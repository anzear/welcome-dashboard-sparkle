---
name: Pathway nodes are immutable after creation
description: In Data Review, existing pathway node labels (feedstock, process technology, product, application/market) can never be edited; only groups, status, and visibility
type: feature
---
In Data Review → Pathways, the four node labels of an existing pathway are read-only. Nodes are set only at creation (New Pathway dialog or Excel import). The Edit pathway dialog shows node values as read-only fields; editable items are limited to groups, status, and visibility. Never re-add node editing or the node-change consequences step for existing pathways.
